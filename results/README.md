# Results

## Re-evaluation benchmark

`time_safe_benchmark.csv` is generated by `src/time_safe_benchmark.py`. The
benchmark uses three expanding-window validation folds on the development
period and reserves the final 15% of dates for one final evaluation. Lag and
rolling features are calculated separately for each ATM from past observations
only.

| Model | Final-test sMAPE | WAPE | MAE |
|---|---:|---:|---:|
| XGBoost, zero-handled | **42.60%** | **32.12%** | **15,438.71** |
| XGBoost, raw active period | 42.94% | 32.33% | 15,539.38 |
| Naive lag-1, raw active period | 56.40% | 52.11% | 25,045.70 |

The zero-handled XGBoost model is the strongest model in this benchmark. This
is a comparison within the tested model set, not a claim that 42.60% is the
lowest possible error on the dataset.

## Archived course experiments

`standardized_models_results.xlsx` contains 28 sheets covering Linear
Regression, XGBoost, LSTM and N-BEATS across feature, sequence-length,
clustering and zero-handling configurations.

The lowest weighted sMAPE recorded in the archived experiments is 27.84% for
XGBoost with combined calendar and temporal features. It is retained as an
exploratory comparison rather than reported as final-test performance because
the same holdout influenced both model selection and reporting.
